# 全国12315平台操作指南

本文件记录平台的实际结构、字段与规则，用于生成表单映射和指导浏览器填写。信息核实于 2026-09-17，来源见文末。

平台会改版，字段标签也可能调整。**填写时以页面实际显示为准**；发现本文件与页面不一致时，按页面走，并顺手把差异记下来。

## 一、平台与渠道

全国12315平台由市场监管总局主办。同一业务有多个入口，账号与单据互通：

| 渠道 | 地址 / 说明 |
|---|---|
| 网页 | https://www.12315.cn/ |
| 手机 APP | https://app.12315.cn/ |
| 微信小程序 / 支付宝小程序 / 微信公众号 | 首页页脚二维码进入 |
| 12315 热线 | 消费者在经营者所在地或经营行为发生地拨打 |

原工商12315、质检12365、食药12331、价监12358、知识产权12330 五条热线已整合为 12315 热线及本平台。

首页主要入口：

- **我要投诉**（`/cuser/portal/tscase/notice`）——"您购买商品或接受服务 认为经营者侵犯您的合法权益"
- **我要举报**（`/cuser/portal/jbcase/notice`）——"您发现违反市场监管法律法规的行为"
- **我要咨询**——跳转市场监管法规查询
- **热线办理进度查询**（`/casualuser/`）——查询电话渠道提交的投诉举报进度
- 消费投诉信息公示平台（https://tsgs.12315.cn/）

## 二、投诉与举报的区别

这决定了材料怎么写，必须先分清。

| | 投诉 | 举报 |
|---|---|---|
| 性质 | 消费者权益争议，请求市场监管部门解决（调解） | 反映经营者涉嫌违法线索（行政执法） |
| 主体 | 消费者本人 | 任何人 |
| 结果告知 | 告知受理决定等 | 除法律法规另有规定外，**不再告知处理结果** |
| 须知要求 | 第 9 条：请勿在投诉中含有举报内容 | 第 8 条：请勿在举报中含有投诉内容 |

同时提出两类内容或材料同时含两类内容的，平台会**分别处理**（《办法》第九条）。所以：想要调解与赔偿走投诉，想要查处走举报，写成两份。

## 三、投诉流程

页面步骤条：**选择投诉单位 → 填写消费者信息 → 填写业务信息 → 投诉完成**。

「投诉须知」不是首页入口，而是点击"我要投诉"后的第一屏，需阅读并在倒计时结束后点"同意"。

官方办事指南给出的操作顺序（北京市市场监督管理局，2025-04）：

1. 访问 www.12315.cn，点右上角「请登录」；已有账号直接登录，没有则先注册
2. 点「我要投诉」，阅读《投诉须知》后点「同意」
3. 输入企业名称、统一社会信用代码或注册号，在结果中点「选择企业」
4. 系统显示所选企业信息（企业名称、所属地、联系电话、行业类别、市场类型、地址、所属工商局），确认后点「确认」
5. 填写消费者信息：姓名、联系电话、详细地址，提交
6. 填写投诉的商品或服务信息，勾选「是否同意公示对该企业的投诉」，可添加附件，提交

## 四、字段清单

### 企业检索

搜索框提示语为"请输入企业名称、统一社会信用代码或注册号"——三者任一即可，**不强制要求信用代码**。可选全国或按省范围检索。

**主体务必与凭证一致。** 如果用户手上的订单、小票或活动页面显示的销售方与用户打算投诉的公司不一致，以凭证为准；主体选错会因"不具有处理权限"被不予受理。

**注册地址不等于事发地点。** 表单里的"被投诉对象住所地"由平台按所选企业自动带出；"事发地点"要填用户实际到店的地址，两者不要混。

### 消费者信息

**姓名、联系电话、详细地址**。网页端姓名与电话通常由账号预填；详细地址有长度校验（APP 端模板为最长 40 字符、要求不少于 10 字符）。

### 业务信息（桌面端实测结构，2026-09-18）

路径：登录 → 首页「我要投诉」→ 同意《投诉须知》→ 检索并确认企业 → 提交消费者信息 → **业务信息**。

页面步骤条：选择投诉单位 → 填写消费者信息 → 填写业务信息 → 投诉完成。

**下列字段每次投诉都不同，必须由用户本人提供，技能不得写死、不得代编：**

- 消费金额（元）
- 争议发生时间
- 实际经营地（省/市/区县）
- 详细地点（事发地址）
- 消费者姓名 / 电话 / 通讯地址（账号预填，用户自行核对）

**可复用的表单结构与选项（模板级，供填表指导）：**

| 字段 | 必填 | 说明 |
|---|---|---|
| 商品/服务名称 | 是 | 具体商品名；也可写「活动现场限定商品购买资格」等如实描述 |
| 商品/服务类别 | 是 | 可检索。选「其他…」会多出「其他商品/服务类别」，**仅允许汉字**（不能出现数字） |
| 品牌 | 否 | 关键词 + 列表选择；选不中可留空，勿硬造品牌条目 |
| 销售方式 | 是 | 常见选项：**网购 / 现场 / 电视电话购物及邮购**。类别未选前该框可能为 disabled，选完类别再点开 |
| 消费金额 | 是 | **用户数据** |
| 争议发生时间 | 是 | **用户数据**；readonly，走日期控件 |
| 投诉问题类别 | 是 | 可检索。选「其他…」会多出「其他投诉问题类别」，**仅允许汉字** |
| 实际经营地 | 是（选「现场」等时出现） | 城市选择器有 **省份 / 城市 / 区县** 三个页签，要逐级点，不能只点省份 |
| 详细地点 | 是 | **用户数据** |
| 处理单位 | 是 | 单选：**投诉对象住所地处理单位** 或 **投诉对象实际经营地处理单位**；选定后系统带出对应分局 |
| 投诉内容 | 是 | **上限约 400 字**；超长会被截断或无法提交 |
| 诉求内容 | 是 | **勾选**，不是自由文本。选项：修理 / 重做 / 更换 / 退货 / **补足商品数量** / 退赔费用 / **赔偿损失** / 停止侵权、核定侵权责任 |
| 是否同意公示 | 是 | 是 / 否，由用户决定 |
| 添加附件 | 否 | jpg/jpeg/png/pdf/mp3/mp4，单文件 ≤5MB，最多 4 个；含个人信息的附件由用户本人上传 |

**ODR 绿色通道** 出现在「确认企业信息」页（若该企业在名录内），不是业务信息页字段。

**本类活动（抽签限购到店无货）实测可用的类别取值（模板参考，非强制）：**

- 商品/服务类别：其他收藏品和工艺品（或其他更贴切项）→ 其他商品/服务类别写「周年限量收藏展示礼盒」等纯汉字描述
- 投诉问题类别：其他合同问题 → 其他投诉问题类别写「抽签限购到店无货且未公示投放数量」等纯汉字描述
- 销售方式：现场（到店核销 / 提货场景）
- 处理单位：事件发生在外地门店时，通常选「实际经营地处理单位」，以便属地市场监管部门核查现场；**最终由用户确认**

**已知渠道名（公开信息，非个案）：** 部分宝可梦卡牌线下限购抽选通过微信小程序「宝可梦卡牌会员」等官方会员渠道发布；具体以用户规则页截图为准。

**网页禁粘贴：** 部分输入框拦截 `onpaste` / Ctrl+V。可在浏览器控制台执行放行片段后粘贴；或用自动化直接设 `input.value` 再触发 `input`/`change`；或由用户手打 / 语音输入。准备包正文务必压到 400 字内。

**通用填法：**

| 字段 | 填法 |
|---|---|
| 商品/服务名称 | 写具体商品名称或如实描述购买资格 |
| 品牌 | 按实际品牌填写，选不中可空 |
| 销售方式 | 以实际为准：线下到店选「现场」；小程序购可按页面选项选「网购」并如实说明 |
| 订单号（若页面出现） | 有编号就填，没有填「无」，不要编 |
| 消费金额 / 争议时间 / 经营地 / 详细地点 | **一律用户提供，不入库、不代填** |
| 投诉内容 | 用 `complaint-package.md` 模板，客观陈述 + 1–3 条请求，不写「责令」「欺诈」 |
| 诉求勾选 | 与用户真实诉求对齐；补购机会对应「补足商品数量」，补偿对应「赔偿损失」 |

## 五、《投诉须知》要点

- **受理范围**：投诉指消费者为生活消费需要购买、使用商品或接受服务，与经营者发生消费者权益争议，请求市场监管部门解决该争议的行为。
- **材料要求**：应当提供具体的投诉请求以及相应的消费者权益争议事实依据，并对材料真实性负责。
- **不予受理情形**（7 项）：
  1. 投诉事项不属于市场监管部门职责，或本机关不具有处理权限
  2. 法院、仲裁机构、市场监管部门或其他行政机关、消协等已受理或处理过同一争议
  3. 不是为生活消费需要，或不能证明与被投诉人之间存在消费者权益争议
  4. 知道或应当知道权益受到侵害之日起超过三年（法律另有规定除外）
  5. 未提供《办法》第十条第一款、第十一条规定的材料，或提供虚假材料
  6. 冒用他人名义投诉，或拒不配合核验真实身份
  7. 法律、法规、规章规定的其他情形
- **受理时限**：自收到投诉之日起 **7 个工作日**内作出受理或不予受理决定并告知投诉人。
- **调解**：经双方同意采用调解；自投诉受理之日起 **60 日**内投诉人与被投诉人未能达成调解协议的，终止调解。终止调解的，自决定之日起 7 个工作日内告知双方。鉴定、检测时间不计入调解期限。
- 一事一单；平台同时提供 12315 热线作为渠道之一。

## 六、登录、注册与实名认证

- **必须登录**才能提交。未登录时访问投诉页面会弹登录框。登录方式为用户名/手机号 + 密码 + 验证码。
- **注册**要求：用户名（4–20 位英文或数字，或 2–10 位中文）、密码（6–15 位）、手机号、图片验证码、短信验证码，并勾选《用户注册条款》。
- **实名认证**提供三种方式：支付宝授权、微信授权、扫脸识别（需通过平台官方 APP）。认证结果保存**姓名与身份证号**。
- **不实名无法提交**：APP 端代码会在未认证时弹出实名提示并隐藏提交按钮，理由是"用户不提供真实身份信息的，网络运营者不得为其提供相关服务"。
- **替代渠道**：平台在实名认证页面明确提示——无法在平台完成实名认证的消费者，可以拨打经营者所在地或经营行为发生地的 12315 电话进行投诉。

这三步全部由用户本人完成。

## 七、两个勾选项的含义

**是否同意公示对该企业的投诉**——影响本次投诉信息是否进入全国12315消费投诉信息公示平台（依据《市场监督管理投诉信息公示暂行规则》）。由用户决定。

**ODR 绿色通道**（投诉须知第 8 条）——勾选即同意进入和解程序，被投诉人应在 **10 个工作日**内与投诉人协商和解。适合希望快速和解、对方有响应意愿的场景；由用户决定。
