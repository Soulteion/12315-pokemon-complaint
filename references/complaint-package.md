## 一、事实时间线的写法

只写可核查的事件，每条带日期；宁可少写，不要写"大概""应该"。

```markdown
- 【年-月-日】主办方发布【活动名称】活动信息，规则中未公布各商品备货数量
- 【年-月-日】本人通过【抽签渠道】参与购买资格抽签
- 【年-月-日】抽签结果公布，本人抽中【日期 时段】的购买时段
- 【年-月-日 时间】本人按抽中时段到达【门店名称】，目标商品【商品名称】已售罄
- 【年-月-日】本人通过【渠道】联系客服反映，答复为【如实记录】
```

## 二、投诉内容正文

### 简洁版（约 300 字，适配表单字数较紧时）

```
本人于【日期】参与由宝可梦（上海）玩具有限公司举办的【活动名称】。该活动通过抽签确定购买时段，但主办方在活动规则公布时及抽签结果公布时，均未公布本次各商品的备货数量或库存总量。

本人抽中的购买时段为【日期 时段】。本人按该时段到达【门店名称】时，目标商品【商品名称】已经售罄，未能完成购买。

商品数量与供应情况直接决定参与者能否实现购买目的。本人认为，在未告知供应数量的情况下参与抽签并接受被分配的时段，参与者无法对自己的购买机会作出合理判断，本人也因此未能在活动期间购得所需商品。

投诉请求：
1. 请被投诉方就本次活动未提前公布货品数量、以及本人按抽中时段到店后商品已售罄的情况作出说明；
2. 【诉求二】；
3. 【诉求三】。

以上事实有本人提交的抽签记录、活动规则页面截图及现场照片可供核查。
```

### 详细版（需要完整陈述经过时使用）

在简洁版基础上补充三段：

1. **规则披露情况**：活动规则页面上关于数量、限购、库存的原话或"未作任何说明"的明确表述，注明页面获取日期与链接。
2. **沟通经过**：联系客服的时间、渠道、答复内容、工单号；没有沟通过就写"截至提交投诉之日，尚未获得被投诉方的正式答复"。
3. **法律依据（可选）**：见 `references/legal-basis.md`，只引用与本人事实确实对应的条文，并按该文件的适用条件说明。事实对不上就不要引用——引用不当会让整份材料显得不专业。

## 三、诉求措辞库

诉求要具体、可执行，能被对方明确回应。按用户实际情况挑 1–3 条，不要堆砌。

**说明与致歉**

- 请被投诉方就本次活动货品数量的披露情况及本人按抽中时段到店后商品售罄的情况作出书面说明。
- 请被投诉方就未提前公布货品数量导致参与者难以判断购买机会一事向本人作出说明并致歉。

**补救购买机会**

- 请被投诉方为本人提供【商品名称】的等条件购买机会（同款、同价、免于再次抽签）。
- 请被投诉方在本活动的后续补货或返场安排中，为本次因时段靠后而未能购买的参与者提供优先购买资格。

**退款与补偿**

- 请被投诉方退还本人为参加本次活动实际支出的【费用项目】【金额】元。

**规则改进**

- 请被投诉方在后续同类活动中提前公布各商品的备货数量或限购规则，使参与者在参与抽签前能够作出合理判断。
- 建议被投诉方按备货数量与签数匹配的方式设置抽签机制，避免时段靠后者必然无货。

**组合示例**（本案典型）

1. 请被投诉方就本次活动未提前公布货品数量及本人到店后商品售罄的情况作出说明；
2. 请被投诉方为本人提供目标商品的等条件购买机会，或在后续补货中提供优先购买资格；
3. 请被投诉方在后续同类活动中提前公布备货数量信息。

## 四、证据清单与取证要点

| 证据 | 取证要点 |
|---|---|
| 抽签结果页 | 截图需含账号标识、抽中时段、页面时间；能录屏更好。避免只有一张裁切图 |
| 活动规则页 / 官方公告 | 要能体现"未公布数量"这一事实——保存完整长截图 + 页面链接 + 获取日期。链接会失效，截图是主力 |
| 售罄现场 | 照片或视频，尽量包含到店时间信息（手机拍摄自带拍摄时间）；店员的答复记为文字并注明时间与对象 |
| 客服沟通记录 | 聊天截图要带时间与账号；自己参与的通话录音一般可作为证据保存，但不要录制与本人无关的他人通话 |
| 参与凭证 | 订单、支付记录、会员记录、抽签编号、邀请记录 |
| 其他参与者的公开反馈 | 仅作背景参考并注明来源，不作为主要证据；不要收集或上传他人的姓名、电话等个人信息 |

上传前两件事：

1. **遮挡无关个人信息**——画面里他人的姓名、电话、住址、证件号、二维码要打码，自己的证件号也不必出现（消费者信息字段已经完成实名，正文里不要写身份证号）。
2. **命名清晰**——用「序号-内容-日期」命名，例如 `01-抽签结果-20260215.jpg`。附件按诉求和时间的顺序排列，方便承办人核对。

## 五、提交前检查表

- [ ] 被投诉主体名称与购物凭证、活动页面上的销售方一致
- [ ] 投诉正文为争议陈述与调解请求，不含举报内容、不含"欺诈""恶意"等未定性表述
- [ ] 时间线中每个日期都能在证据中找到对应
- [ ] 消费金额、数量与凭证一致；无支出就如实填无
- [ ] 诉求具体、可执行，且是用户本人真实想要的
- [ ] 正文与附件中无无关的他人个人信息
- [ ] 已向用户解释并确认「是否同意公示」与「ODR 绿色通道」两个勾选项
- [ ] 已确认同一争议未在其他渠道被受理或处理过
- [ ] 用户已明确同意提交（用户说"先别提交"时停在此处）
